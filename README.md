# ZapretGUI

GUI для [zapret2](https://github.com/bol-van/zapret2), созданный для того, чтобы сделать его использование проще и удобнее.

Проект полностью сделан с помощью ИИ. Главная цель — скрыть сложность настройки zapret2 за простым интерфейсом и постепенно добавить автоматизацию и полезные функции.

## Возможности

* включение и отключение защиты;
* выбор и настройка стратегий;
* мониторинг;
* пользовательские стратегии;
* тёмная и светлая тема;
* простой современный интерфейс.

## Статус

Проект находится на стадии MVP и активно развивается.
