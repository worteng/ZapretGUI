# ZapretGUI — план проекта

## 1. Концепция

**ZapretGUI** — современный Linux GUI для управления **zapret2**.

Главная цель — сделать работу с zapret максимально простой для новичков и обычных пользователей Linux, при этом сохранить мощные возможности для продвинутых пользователей.

Основной принцип:

> Пользователь не должен разбираться в zapret, nftables, параметрах desync, systemd и сетевых правилах, чтобы просто включить защиту.

Пользователь должен:

1. установить ZapretGUI;
2. запустить;
3. при необходимости установить zapret2 автоматически;
4. нажать ON;
5. выбрать стратегию при необходимости;
6. закрыть приложение;
7. продолжить пользоваться системой.

При этом ZapretGUI должен быть полноценным менеджером, а не просто графической оболочкой над несколькими shell-командами.

---

# 2. Целевая аудитория

Основная аудитория:

* новые пользователи Linux;
* обычные пользователи Linux;
* пользователи, которым существующие способы настройки zapret кажутся слишком сложными.

Вторичная аудитория:

* продвинутые пользователи;
* пользователи, которым нужен ручной контроль;
* разработчики и тестировщики.

Главный принцип интерфейса:

> **Просто снаружи, мощно внутри.**

Обычный пользователь не должен видеть технические параметры.

Продвинутые функции должны находиться в отдельных разделах и/или Developer Mode.

---

# 3. Основные цели

ZapretGUI должен:

* управлять zapret2;
* автоматически обнаруживать установленный zapret2;
* автоматически устанавливать zapret2 при необходимости;
* автоматически устанавливать зависимости;
* управлять запуском и остановкой;
* работать как systemd-служба;
* иметь простые готовые стратегии;
* поддерживать пользовательские стратегии;
* автоматически тестировать соединение;
* автоматически искать рабочие стратегии;
* мониторить выбранные сервисы;
* иметь режим Autopilot;
* автоматически восстанавливаться при проблемах;
* иметь полноценную диагностику;
* иметь понятные логи;
* работать на разных Linux-дистрибутивах;
* не зависеть от конкретного Desktop Environment;
* иметь современный минималистичный интерфейс.

# 12. Autopilot

Autopilot — одна из ключевых будущих функций проекта.

Отличие:

### Auto

Один раз автоматически находит подходящую конфигурацию.

### Autopilot

Постоянно следит за состоянием и автоматически принимает решения.

Autopilot должен:

1. мониторить выбранные сервисы;
2. обнаруживать проблемы;
3. определять, действительно ли проблема связана с текущей стратегией;
4. запускать диагностику;
5. пробовать альтернативные стратегии;
6. тестировать результаты;
7. выбирать рабочую;
8. применять её;
9. сохранять результат;
10. продолжать мониторинг.

Пример:

```text
YouTube — ошибка

Проверка...

Текущая стратегия       ✗
Стратегия #12            ✗
Стратегия #18            ✗
Стратегия #23            ✓

✓ Найдена рабочая стратегия

Применение...
```

Autopilot должен быть полностью отключаемым.

```text
                ZAPRETGUI

        ┌──────────────────────┐
        │                      │
        │          ●           │
        │       РАБОТАЕТ       │
        │                      │
        │      [ ON / OFF ]    │
        │                      │
        └──────────────────────┘

             Авто
             YouTube
             Gaming
             Maximum
             Custom

 ┌─────────────────────────────────────────────┐
 │                                             │
 │  Monitoring       Diagnostics       Logs    │
 │                                             │
 │  YouTube          Full             Events   │
 │  Discord          Web              Errors   │
 │  Telegram         Report           Debug    │
 │                                             │
 └─────────────────────────────────────────────┘
```

При этом за простым интерфейсом находится мощная система:

```text
                 ZapretGUI
                      │
          ┌───────────┼───────────┐
          │           │           │
       Strategy   Monitoring   Diagnostics
          │           │           │
          └───────────┼───────────┘
                      │
                  Automation
                      │
                   Autopilot
                      │
                ┌─────┴─────┐
                │           │
             Zapret2     Firewall
                │           │
                └─────┬─────┘
                      │
                    Linux
```

**Основная идея проекта:**

> **ZapretGUI должен убрать необходимость вручную разбираться с zapret, превратив его из набора технических инструментов в нормальное современное Linux-приложение.**
