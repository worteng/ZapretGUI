# ZapretGUI — UX Specification (Phase 1)

Дата: 18.08.2026 · Статус: черновик для ревью · Охват: **MVP-first**
Стек UI: **HTML/CSS/JS в pywebview (WebKitGTK)**, язык интерфейса — **только русский**, стиль — **собственный современный**.

Связанные документы: `ПЛАН.md` (требования §4–§20), `docs/research/01-zapret2-technical-research.md` (технические ограничения).

---

## 1. Принципы UX

1. **Просто снаружи, мощно внутри.** MVP-экраны не содержат ни одного технического термина. «Стратегия», «проверка», «списки» — максимум абстракции для новичка.
2. **Одна главная задача на экран.** Главный экран = один переключатель и статус. Всё остальное — вторично.
3. **Приложение не запускается от root.** Любое действие, требующее прав (включить, применить стратегию, обновить списки), подтверждается системным диалогом прав (pkexec) — пользователь привык к такой модели.
4. **Защита работает без GUI.** Интерфейс лишь показывает состояние системы; при закрытии окна zapret продолжает работать.
5. **Статус всегда однозначен.** Четыре состояния, каждое = точка + слово + своя карточка действий. Никаких «многоточий» без объяснения.
6. **Ненавязчивость.** Нет уведомлений при нормальной работе; тосты и системные уведомления — только по делу.
7. **Предсказуемость.** Одинаковый словарь кнопок и состояний на всех экранах; каждая кнопка — глагол действия («Включить», «Применить», «Проверить»).

## 2. Дизайн-система

### 2.1 Цвет

Структура: 1 нейтральный рамп (холодный, технический), 1 акцентный (синий), 4 статусных (success/error/warning — в MVP; info появится позже). Такой же нейтральный и статусные используются в тёмной теме с учётом приглушения.

Семантика статусов (задана ПЛАНом §7):

| Токен | Значение | Цвет света | Цвет тьмы |
|---|---|---|---|
| `--status-active` | РАБОТАЕТ | `#15803D` | `#4ADE80` |
| `--status-inactive` | ВЫКЛЮЧЕНО | `#6B7280` | `#9CA3AF` |
| `--status-error` | ОШИБКА | `#B91C1C` | `#F87171` |
| `--status-degraded` | ПРОБЛЕМА | `#B45309` | `#FBBF24` |

Примитивные токены (не применять в компонентах напрямую):

```css
:root {
  /* нейтрали — светлая */
  --gray-0:  #FFFFFF;  /* поверхность по умолчанию */
  --gray-50: #F7F8FA;  /* фон окна */
  --gray-100:#EEEFF3;  /* фон ховера, подложка */
  --gray-200:#E1E3E9;  /* тонкий бордер, отделитель */
  --gray-300:#C9CDD6;  /* бордер */
  --gray-400:#9BA1AD;  /* фокус-кольцо (нейтральное) */
  --gray-500:#6B7280;  /* иконки неактивные */
  --gray-700:#3F454E;  /* вторичный текст */
  --gray-900:#16181D;  /* основной текст */

  /* акцент — синий */
  --blue-100:#DBEAFE;
  --blue-400:#60A5FA;
  --blue-500:#3B82F6;
  --blue-600:#2563EB;
  --blue-700:#1D4ED8;
}
html[data-theme="dark"] {
  --gray-0:  #141517;
  --gray-50: #17181C;
  --gray-100:#1E2025;
  --gray-200:#26282E;
  --gray-300:#33363D;
  --gray-400:#4B4F58;
  --gray-500:#8A919C;
  --gray-700:#B6BCC6;
  --gray-900:#ECEEF2;
  --blue-600:#3B82F6; /* основной синий в тёмной теме смещён светлее */
  --blue-700:#60A5FA;
}
```

Семантические токены — единственный уровень, который используют компоненты:

```css
:root {
  --bg-page:      var(--gray-50);
  --bg-surface:   var(--gray-0);
  --bg-hover:     var(--gray-100);
  --bg-accent-soft: var(--blue-100);
  --border-subtle:  var(--gray-200);
  --border:         var(--gray-300);
  --text-primary:   var(--gray-900);
  --text-secondary: var(--gray-700);
  --text-disabled:  var(--gray-500);
  --accent:      var(--blue-600);
  --accent-hover:var(--blue-700);
  --on-accent:   #FFFFFF;
  --focus-ring:  var(--blue-500);
  /* статусы см. таблицу выше */
  --shadow-card: 0 1px 2px rgb(0 0 0 / .04), 0 8px 24px rgb(0 0 0 / .06);
}
```

Правила применения:
- Акцент = интерактив. Синий не используется для статического текста-декора; синий текст = кликабельно.
- Один акцентный цвет на экран: залита ровно одна primary-кнопка, остальные — нейтральные.
- Статусы живут в одной роли: точка/слово/бейдж. Красный — только «ОШИБКА» и разрушающие действия, жёлтый — только «ПРОБЛЕМА».
- Статус никогда не несётся только цветом — всегда пара «точка + текст», плюс в карточках иконка.
- Контраст: текст 4.5:1, UI-элементы 3:1 (значения подобраны под эти пороги, проверка — при ревью).
- Тёмная тема — приглушённая: фоны не чисто чёрные, статусы светлее (для контраста на тёмном), насыщенность средней зоны снижена.

Механизм переключения темы: атрибут `data-theme` на `<html>` + `prefers-color-scheme` как источник «Авто». Один механизм, без дублей.

### 2.2 Типографика

Шрифт: системный стек (никаких загрузок — приложение офлайн):

```css
--font-sans: "Noto Sans", "Cantarell", "Inter", "Segoe UI", system-ui, sans-serif;
--font-mono: "Noto Sans Mono", "DejaVu Sans Mono", "JetBrains Mono", monospace; /* логи */
```

Шкала (минимальная, по ролям):

| Токен | Размер/вес | Роль |
|---|---|---|
| `--text-display` | 32px / 700 | Главный статус «РАБОТАЕТ» |
| `--text-h1` | 22px / 650 | Заголовок экрана |
| `--text-h2` | 16px / 600 | Заголовок карточки / раздела |
| `--text-body` | 14px / 400 | Основной UI-текст (по умолчанию) |
| `--text-caption` | 13px / 400 | Подписи, мета-информация, описания |
| `--text-micro` | 12px / 500 | Бейджи, метки уровней логов |

Правила:
- `line-height`: заголовки 1.25, текст 1.5 (unitless); короткие подписи — 1.4.
- `font-variant-numeric: tabular-nums` для таймеров, uptime, счётчиков.
- Буквица самонаблюдения: для слов-статусов («РАБОТАЕТ») — `text-transform: uppercase` + `letter-spacing: .08em`, сам текст в натуре («Работает»).
- Длинный текст (онбординг, описания) — не шире 60–70 знаков.
- Моно для логов (`--font-mono`), размер 12–13px, без сглаживания вопросов.
- `-webkit-font-smoothing: antialiased` один раз на корне.

### 2.3 Спейсинг, углы, тени

```css
--space-1: 4px;  --space-2: 8px;  --space-3: 12px;
--space-4: 16px; --space-5: 24px; --space-6: 32px;
--space-8: 48px;
--radius-sm: 8px;   /* кнопки, инпуты, строки */
--radius-md: 12px;  /* мелкие карточки, диалоги */
--radius-lg: 16px;  /* крупные карточки, модалки */
--radius-full: 999px; /* пилюли, статус-бейджи, тумблеры */
```

- Карточки: padding 20–24px, бордер `--border-subtle`, радиус `--radius-lg`.
- Страницы: padding 32px, контент по центру, max-width 880px.
- Тень только на «плавающих» слоях (модалки, тосты); карточки — бордером, не тенью.

### 2.4 Анимации

| Случай | Длительность | Кривая |
|---|---|---|
| Hover/нажатия | 120ms | `ease-out` |
| Появление карточек, страниц (fade + 8px сдвиг) | 200ms | `cubic-bezier(.2, 0, 0, 1)` |
| Смена статуса (цвет точки/слова) | 300ms | `cubic-bezier(.2, 0, 0, 1)` |
| Тумблер ON/OFF (позиция ручки) | 250ms | spring-подобная `cubic-bezier(.34, 1.56, .64, 1)` |
| Прогресс автонастройки | плавная, сегментами | — |

- Появление «пульса» у точки статуса — только при переходе (loading), не в покое.
- `prefers-reduced-motion: reduce` — отключает все анимации кроме opacity-переходов.
- Анимации не блокируют ввод; кнопки в состоянии загрузки — спиннером.

## 3. Окно и навигация

### 3.1 Окно (pywebview)

- Размер по умолчанию **960×640**, минимальный **760×540**, ресайзлятся пользователем.
- **Нативный тайтлбар** в MVP (решение): DE-независимость, нет возни с drag-регионами WebKitGTK и кнопками сворачивания в GNOME/Hyprland. Собственный frameless-тайтлбар — открытый вопрос на потом.
- Закрытие окна (`×`) не завершает приложение — скрывает в tray (см. §6).
- Иконка в тайтлбаре и tray: единый SVG-щит со статусной точкой (уточняется дизайнером; placeholder — в реализации).

### 3.2 Левый dock

Вертикальный dock 56px, иконки 22px + тултип справа при hover (`title`), активный пункт — синий `--accent` и подсветка `--bg-hover`. Внизу dock — кнопка «Выйти» (поверх — диалог подтверждения).

```
┌─────────────────────────────────────────────┐
│ ▐ icon▌  Главная        (активна)            │
│  icon    Стратегии                            │
│  icon    Мониторинг                           │
│  icon    Автопилот                            │
│  icon    Диагностика                          │
│  icon    Логи                                 │
│  icon    Настройки                            │
│                                               │
│  ⋮                                            │
│  icon    Выйти                               │
└─────────────────────────────────────────────┘
```

- Тултип = название раздела; иконки с `aria-label`.
- Скролл dock'а не нужен — пунктов 7, влезают в любую высоту окна.
- Автопилот в MVP — экран-заглушка «В разработке» (пункт остаётся, чтобы dock не менялся в будущем).

## 4. Экраны MVP (детально)

### 4.1 Onboarding (только первый запуск)

Три шага, индикатор шагов сверху (сегменты), кнопки внизу. При пропущенном первом запуске (zapret2 уже установлен и включён) — шаг 1+2 свернуты в один экран «Проверка пройдена → Готово».

**Шаг 1 — Приветствие**

```
┌────────────────────────────────────────────┐
│  ZAPRETGUI                                 │
│  (иконка-щит, 64px)                        │
│                                            │
│  Добро пожаловать                          │
│  Проверим систему и подготовим всё         │
│  необходимое. Займёт минуту.               │
│                                            │
│                          [ Продолжить ]    │
└────────────────────────────────────────────┘
```

Тон: тёплый, коротко. Кнопка-глагол «Продолжить».

**Шаг 2 — Проверка системы**

Чеклист, каждый пункт — иконка готовности слева, название, пояснение (только при ошибке):

```
┌────────────────────────────────────────────┐
│  Проверка системы                          │
│                                            │
│  ✓  Система определена                     │
│     Linux x86_64                           │
│  ✓  systemd найден                         │
│  ✓  Сеть доступна                          │
│  ⚠  zapret2 не найден                      │
│                                            │
│  Установить zapret2 автоматически?         │
│  [  Установить  ]  [  Пропустить  ]        │
└────────────────────────────────────────────┘
```

- Состояния пункта: `✓` зелёный, `⚠` жёлтый, `✗` красный, спиннер — во время проверки.
- Каждый чекин мгновенный (<1с), результаты приходят пакетом.
- **zapret2 не найден** → блок «Установить?» → установка с прогрессом (полоса + этапы: «Определение системы → Загрузка → Установка → Настройка службы»).
- **Ошибка сети/NET-systemd**: кнопка «Продолжить» блокирована, показ конкретной причины и куда смотреть («Проверьте подключение или установите zapret2 вручную»).
- «Пропустить» допустим: приложение откроется, но ON/OFF будет выключен до установки (главный экран покажет карточку-подсказку, см. 4.2).

**Шаг 3 — Готово**

```
┌────────────────────────────────────────────┐
│  ✓  Готово                                 │
│  ZapretGUI настроен.                       │
│  Включите защиту одним переключателем.     │
│                                            │
│  [  Перейти на главный экран  ]            │
└────────────────────────────────────────────┘
```

### 4.2 Главный экран

Центральная композиция по вертикали: статус → переключатель → карточка стратегии → (по необходимости) карточка проблемы.

```
┌────────────────────────────────────────────┐
│                                            │
│              ●                             │
│            РАБОТАЕТ                        │
│                                            │
│   ┌────────────────────────────────┐       │
│   │  [ Выключить ]                 │       │
│   └────────────────────────────────┘       │
│                                            │
│   ┌────────────────────────────────┐       │
│   │  Стратегия                      │       │
│   │  Авто                           │  →   │
│   │  Подобрана автоматически       │       │
│   └────────────────────────────────┘       │
│                                            │
│   Защита активна · Перезапуск 3 ч назад    │
└────────────────────────────────────────────┘
```

**Статус** — точка 12px (пульс только в переходе) + слово капиталью 32px. Четыре состояния:

| Состояние | Точка | Слово | Доп. инфо под статусом |
|---|---|---|---|
| active | зелёная | РАБОТАЕТ | — |
| inactive | серая | ВЫКЛЮЧЕНО | «Защита выключена» |
| degraded | жёлтая | ПРОБЛЕМА | «Часть проверок не работает. Что проверить →» |
| error | красная | ОШИБКА | причина одной строкой + кнопки [Повторить] [Диагностика] |

**Переключатель** — широкая пилюля (мин. 220×52px), цвет = `--accent` при включённом, `--gray-300` при выключенном; слова «Выключить»/«Включить» на белом/тёмном по контрасту. Состояния: on / off / loading (спиннер в ручке-иконке, текст «Проверка…») / disabled (zapret2 не установлен: текст «Установить zapret2» + поведение как кнопка на онбординг).

Поток **включения** (клик «Включить»):
1. Пилюля → loading «Проверка…»; точка статуса — спиннер.
2. Последовательные шаги с прогрессом под пилюлей (мини-чеклист, по ~0.4–1.5с):
   - «Применяю стратегию…»
   - «Запускаю службу…»
   - «Проверяю соединение…»
3. Успех → статус РАБОТАЕТ (зелёный, 300ms переход). Ошибка на любом шаге → статус ОШИБКА + причина + [Повторить].
4. Запрос прав (pkexec) появляется до шага 1; отказ → тост «Нужны права для включения защиты», статус не меняется.

Поток **выключения**: без подтверждения (не разрушающее действие): пилюля loading «Останавливаю…» ~1с → статус ВЫКЛЮЧЕНО.

**Карточка стратегии** — читается как кликабельная (бордер, ховер, «→»): название + короткое описание текущей стратегии. Клик → раздел «Стратегии». Показывается всегда.

**Мета-строка** (13px, вторичный цвет): «Защита активна · Перезапуск 3 ч назад» / «Защита выключена · Автозапуск включён» и т.п. — одна строка, не более.

**Карточка-подсказка** (zapret2 не установлен): жёлтая, внутри: «zapret2 не установлен. Без него защита не работает.» + [Установить сейчас]. Переключатель одновременно disabled.

### 4.3 Стратегии

```
┌────────────────────────────────────────────┐
│  Стратегии                                 │
│                                            │
│  ┌────────────────────────────────────┐    │
│  │ (●)  Авто                  (активна)│    │
│  │      Подбирает параметры           │    │
│  │      автоматически                 │    │
│  ├────────────────────────────────────┤    │
│  │ ( )  YouTube                        │    │
│  │      Фокус на работу YouTube        │    │
│  ├────────────────────────────────────┤    │
│  │ ( )  Игровая                        │    │
│  │      Минимальный отклик для игр     │    │
│  ├────────────────────────────────────┤    │
│  │ ( )  Максимальная совместимость     │    │
│  │      Меньше вмешательства,          │    │
│  │      работает почти везде           │    │
│  └────────────────────────────────────┘    │
└────────────────────────────────────────────┘
```

- Радио-выбор строкой. Описания — одна-две строки, человеческим языком.
- У активной — бейдж «Активна» (`--bg-accent-soft`, синий текст) с правой стороны.
- **Применение**: клик по строке ≠ мгновенному применению. Появляется диалог (только если защита включена):

```
┌─────────────────────────────────────────┐
│  Применить стратегию «YouTube»?          │
│  Защита перезапустится (1–2 секунды).    │
│                                         │
│  [  Применить и перезапустить  ]  [ Отмена ]
└─────────────────────────────────────────┘
```

  - Кнопка подтверждения повторяет действие — «Применить и перезапустить».
  - После применения — тост «Стратегия «YouTube» применена» (нейтральный, 3с).
  - Если защита выключена: выбор сохраняется молча → главный экран покажет новую стратегию; тост «Сохранить стратегию» не нужен.
- **«Моя стратегия»** — в MVP отсутствует как пункт списка (см. Открытые вопросы). Пункт появится, когда появится редактор/импорт.

### 4.4 Настройки (MVP-набор)

Секции карточками, заголовки `--text-h2`, строки настроек с явными бинарными названиями (теглый-он семантически):

```
┌────────────────────────────────────────────┐
│  Настройки                                 │
│                                            │
│  ┌─ Запуск ──────────────────────────────┐ │
│  │ Автозапуск защиты при старте системы    │ │
│  │ ──────────────────────────── [toggle] │ │
│  ├───────────────────────────────────────┤ │
│  │ Обновлять списки автоматически         │ │
│  │ ──────────────────────────── [toggle] │ │
│  │ Обновить списки сейчас        [button]│ │
│  ├───────────────────────────────────────┤ │
│  │ Проверять сервисы каждые     [5 мин ▾] │ │
│  └───────────────────────────────────────┘ │
│                                            │
│  ┌─ Внешний вид ─────────────────────────┐ │
│  │ Тема                         [Авто ▾]  │ │
│  └───────────────────────────────────────┘ │
│                                            │
│  ┌─ О программе ─────────────────────────┐ │
│  │ ZapretGUI 0.1.0 · zapret2 1.0.4        │ │
│  └───────────────────────────────────────┘ │
└────────────────────────────────────────────┘
```

- Toggle-подписи именуют включённое состояние («Автозапуск защиты при старте системы», не «не выключать автозапуск»).
- «Обновить списки сейчас» — видимо только при включённом автоматическом обновлении; после клика — тост «Списки обновлены» или ошибка с причиной.
- Тема: Автоматически / Светлая / Тёмная (select).
- Правила: тост при применении, ошибка pkexec/службы — красным тостом с текстом причины.

## 6. Tray и уведомления

### Tray (обвязка pywebview, вне веба)

Иконка = щит со статусной точкой (тот же SVG, рендерится Python-стороной или статичный набор по статусу). Клик левой — открыть/скрыть окно. Меню (правый клик):

```
Открыть ZapretGUI
Включить/Выключить защиту      ← глагол по текущему состоянию
Проверить сейчас
──────────────
Выйти
```

- Закрытие окна `×` → скрытие в tray. Первый запуск — окно показывается, tray-иконка есть.
- «Выйти» — диалог подтверждения, если защита включена: «Остановить защиту и выйти?» [Остановить и выйти] [Отмена]. (По умолч.: защита остаётся работать — это безопасно и ожидаемо; вопрос на подтверждение.)
- Элементы tray-меню: статус (активный пункт-заголовок «Защита: работает»), не кликабелен.

### Уведомления (системные, через обвязку)

| Событие | Тип | Правило |
|---|---|---|
| Нормальная работа | — | тишина |
| Стратегия применена | тост в приложении | 3с, нейтральный |
| Мониторинг: сервисы падают, защита включена | systém + тост | не чаще 1/15 мин, текст: «Не удалось проверить: YouTube, Discord» |
| Ошибка службы zapret | systém + тост | «Защита перестала работать. Откройте ZapretGUI» |
| Успешное восстановление Autopilot | тост | позитивный, но тихий (будущее) |

Анти-спам: если 3+ уведомления об одном и том же подряд — следующее только через 15 минут; кнопка «Проверить сейчас» всегда доступна в tray.

## 8. Доступность (базовый уровень MVP)

- Контраст: тексты ≥ 4.5:1, UI ≥ 3:1 — зашито в токены (§2.1), проверяется при ревью компонентов.
- Статус ≠ только цвет: точка + слово + (в карточках) иконка и текст причины.
- Клавиатура: полный Tab-цикл, видимый фокус (кольцо `--focus-ring` 2px, offset 2px), Enter/Space активируют, Escape закрывает модалки, в модалке — focus trap.
- Dock: иконки с `aria-label` и тултипами; активный пункт дополнительно словом (подпись при фокусе).
- `prefers-reduced-motion`: отключение не-required анимаций (§2.4).
- Формы: label у каждого контрола (не только placeholder).
- Веб-семантика: `role`, заголовки по уровням на экранах; логи — `aria-live="polite"` для новых записей.
